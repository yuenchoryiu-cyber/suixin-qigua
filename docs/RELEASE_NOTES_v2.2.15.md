## 随心起卦 v2.2.15

Pip-Boy 风格桌面起卦 · 梅花 / 六爻 / 奇门 · 自带多模型一键预设

### Highlights
- 开始页易经字雨 + 随机卦象金句
- 占卜体系：梅花易数 / 六爻纳甲 / 奇门遁甲 / **随机起卦**
- 取数：时间 · 数字 · 地理 · 天气 · 颜色 · 随机
- 今日吉凶（一天一次）与多维 bar 评分分享卡
- DeepSeek / 豆包 / Claude / OpenAI / Kimi / 通义 / 智谱等一键接入
- 分享图默认脱敏，不含 API Key；分享卡支持数字雨背景
- **应用内更新（安装版）**：下载更新 → **安装并重启**（静默覆盖，装完自动打开）

### What’s new in v2.2.15
- **修复**：更新时不再把整包再复制一份到「下载」文件夹（此前会像「下了更新包又下了程序」）
- **修复**：点安装后真正静默覆盖并自动重开（`--updated /S --force-run`，并销毁托盘以免进程挂住）
- 文案改为「下载更新 / 安装并重启」，避免误开完整 Setup

Mac 未签名，首次打开可在「隐私与安全性」允许。

### Update tip（已安装用户 · Windows）
1. 打开随心起卦（安装版）
2. 提示新版本时：点 **下载更新** → **安装并重启**
3. 程序会退出、静默安装，并自动重新打开
