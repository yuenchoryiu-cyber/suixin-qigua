## 随心起卦 v2.2.12

Pip-Boy 风格桌面起卦 · 梅花 / 六爻 / 奇门 · 自带多模型一键预设

### Highlights
- 开始页易经字雨 + 随机卦象金句
- 占卜体系：梅花易数 / 六爻纳甲 / 奇门遁甲 / **随机起卦**
- 取数：时间 · 数字 · 地理 · 天气 · 颜色 · 随机
- 今日吉凶（一天一次）与多维 bar 评分分享卡
- DeepSeek / 豆包 / Claude / OpenAI / Kimi / 通义 / 智谱等一键接入
- 分享图默认脱敏，不含 API Key；分享卡支持数字雨背景
- **应用内更新（安装版）**：启动检测 → 下载更新包 → 打开后仅静默更新程序（可跳版本直达最新）
- 完整 Setup 安装前自动结束旧进程，避免与正在运行的程序冲突

### What’s new since v2.2.4
- 应用内差量 / 整包更新（`electron-updater` + `latest.yml`）
- 更新包写入「下载」文件夹，配套「打开更新」启动器（静默安装，不进完整向导）
- 高精度意图细化与追问（API）
- 设置与页脚状态栏整理（API 连通 / 版本号）

### Downloads
| Platform | File |
|----------|------|
| Windows 安装 | `suixin-qigua-2.2.12-win-x64.exe` |
| Windows 便携 | `suixin-qigua-2.2.12-win-portable.exe` |

> 便携版不走应用内差量更新；需要自动更新请使用「Windows 安装」包。  
> 自动更新还会用到同目录下的 `latest.yml` 与 `.blockmap`（已附在本 Release）。

### Update tip（已安装用户）
1. 打开已安装的随心起卦（安装版）
2. 若提示新版本：点 **下载更新包** → **打开更新包（仅更新程序）**
3. 程序将静默更新并重开，无需再跑完整 Setup 向导
