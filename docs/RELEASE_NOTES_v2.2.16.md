## 随心起卦 v2.2.16

Pip-Boy 风格桌面起卦 · 梅花 / 六爻 / 奇门 · 自带多模型一键预设

### Highlights
- 开始页易经字雨 + 随机卦象金句
- 占卜体系：梅花易数 / 六爻纳甲 / 奇门遁甲 / **随机起卦**
- 取数：时间 · 数字 · 地理 · 天气 · 颜色 · 随机
- 今日吉凶（一天一次）与多维 bar 评分分享卡
- DeepSeek / 豆包 / Claude / OpenAI / Kimi / 通义 / 智谱等一键接入
- 分享图默认脱敏，不含 API Key；分享卡支持数字雨背景
- **应用内更新（安装版）**：下载更新 → 安装并重启

### What’s new in v2.2.16
- 用于验证「从 2.2.15 应用内更新」是否有效（功能与 2.2.15 相同）

### Downloads
| Platform | File |
|----------|------|
| Windows 安装 | `suixin-qigua-2.2.16-win-x64.exe` |
| Windows 便携 | `suixin-qigua-2.2.16-win-portable.exe` |
| macOS | `suixin-qigua-2.2.16-mac-universal.dmg` |
| macOS (zip) | `suixin-qigua-2.2.16-mac-universal.zip` |

Mac 未签名，首次打开可在「隐私与安全性」允许。

### Update tip（已安装 2.2.15 的用户）
1. 打开 **2.2.15** 安装版
2. 应提示可升到 **2.2.16**
3. 点 **下载更新** → **安装并重启**
4. 重开后右下角应为 **V2.2.16**
