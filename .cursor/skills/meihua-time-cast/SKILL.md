# 梅花易数 · 随心起卦 v2

实现位于 `src/meihua/`、`src/geo/`、`src/components/ColorMatrixPicker.tsx`、`src/components/CityCascade.tsx`、`src/components/HoldCast.tsx`。

## 取数

- **时间**：上=(年支+月+日)%8，下=(+时支)%8，动=(同下合计)%6
- **数字**：上=数1%8，下=数2%8，动=(1+2+3)%6
- **地理**：上=纬密%8，下=经密%8，动=(纬+经+时支)%6；坐标来自 GPS / 洲→国家→省→城市 / 地图 / 手输
- **天气**：上=|气温|%8，下=湿度%8，动=(气温+湿度+气压尾)%6；气象用 Open-Meteo
- **颜色**：上=R%8，下=G%8，动=(R+G+B)%6；蜂巢色盘点选，用实际 RGB 0–255
- **随机**：本机熵生成三数，算法同数字起卦

## 环境变数（默认开启）

正式起卦前有「按压起卦」：用户按住卦纹默念，松开后记 `holdMs`。

瞬时环境：`E = 年支+月+日+时支+分+秒`，再加按压盐 `H = floor(holdMs/17)+(holdMs%97)`，`mix=E+H`。

地理 / 颜色 / 数字 / 天气 / 随机（及对应六爻种子、奇门定局）把 `mix` 加入上卦、下卦、动爻（或种子/局数）。

设置「复现模式」可关闭 mix，并跳过按压页（同输入同卦，便于对照）。

先天数：乾1兑2离3震4巽5坎6艮7坤8。解读默认走用户自备 API；失败或未配置时回退免费离线简解。
